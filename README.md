# 🌦️ SafeWeather-AI
### AI 기반 기후재난 복지 취약지역 분석 및 지원 우선순위 추천 시스템

## 1. 프로젝트 소개

SafeWeather-AI는 폭염과 한파 등 기후재난에 취약한 고령층 및 노인 1인 가구를 대상으로 지역별 기후 위험과 복지 취약성을 분석하고, 이를 바탕으로 지원 우선순위를 추천하는 데이터 분석 프로젝트입니다.

기후 데이터와 고령인구 및 노인 1인 가구 데이터, 무더위쉼터 및 한파쉼터 데이터를 통합하여 전국 시군구별 취약 특성을 분석하고, 지역별 맞춤형 복지 지원 의사결정을 돕는 것을 목표로 합니다.

## 2. 주제 선정 이유

최근 폭염과 한파 등 이상기후 현상이 심화되면서 기후재난에 취약한 고령층에 대한 사회적 관심과 지원의 필요성이 커지고 있습니다.

특히 고령인구와 노인 1인 가구는 기후재난 발생 시 상대적으로 큰 영향을 받을 수 있으며, 지역별 기후 위험도와 복지시설 공급 수준에도 차이가 존재합니다.

이에 따라 단순히 기온이나 폭염일수만 분석하는 것이 아니라, 고령인구 규모와 노인 1인 가구 비율, 쉼터 공급 현황 등을 종합적으로 고려하여 지역별 복지 취약성을 파악하고 지원 우선순위를 도출하고자 본 주제를 선정하였습니다.

## 3. 데이터 분석 내용

### 3-1. 데이터 수집 및 전처리

다음 데이터를 수집하고 분석 목적에 맞게 전처리하였습니다.

| 데이터 | 주요 내용 |
|---|---|
| 고령인구 데이터 | 지역별 65세 이상 인구 |
| 노인 1인 가구 데이터 | 지역별 노인 1인 가구 현황 |
| 기후 데이터 | 지역별 기온 및 기후 관측 정보 |
| 폭염 데이터 | 지역별 폭염일수 |
| 한파 데이터 | 지역별 한파일수 |
| 쉼터 데이터 | 지역별 무더위쉼터 및 한파쉼터 현황 |

- 데이터 수집 및 정제
- 지역명 및 행정구역 코드 통일
- 시군구 단위 데이터 통합
- 결측치 및 중복 데이터 확인
- 2021~2025년 지역별 데이터 통합

### 3-2. 탐색적 데이터 분석(EDA)

통합 데이터를 활용하여 지역별 기후 위험과 복지 취약 특성을 분석하였습니다.

- 연도별 고령인구 및 노인 1인 가구 변화 분석
- 지역별 폭염일수 및 한파일수 비교
- 지역별 쉼터 공급 현황 분석
- 기후 위험과 복지 취약성 간의 관계 분석
- 쉼터 공급 취약지역 도출

### 3-3. K-Means 군집 분석

K-Means 알고리즘을 활용하여 지역별 기후 및 복지 취약 특성을 군집화하였습니다.

군집 분석을 통해 지역별 취약 유형을 구분하고, 각 군집의 주요 특성을 비교하였습니다.

### 3-4. 지원 우선순위 산정

군집 분석 결과와 지역별 취약성 지표를 활용하여 지역별 지원 우선순위 점수를 산정하였습니다.

분석 결과를 바탕으로 지역을 다음과 같이 구분하였습니다.

- 우선지원
- 주의
- 관심
- 일반

이를 통해 기후재난에 취약한 지역을 파악하고 복지 지원이 필요한 지역을 우선적으로 확인할 수 있도록 하였습니다.

## 4. 프로젝트 결과 및 서비스

분석 결과를 직관적으로 확인할 수 있도록 Streamlit 기반 대시보드를 구현하였습니다.

주요 기능은 다음과 같습니다.

- 전국 시군구별 기후복지 취약지역 지도 시각화
- 시도별 지역 데이터 필터링
- 지원 우선순위 등급별 지역 조회
- 지역별 지원 우선순위 점수 확인
- 등급별 지역 분포 및 상위 취약지역 확인
